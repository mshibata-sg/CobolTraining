# KJBM030 単体テストチェックリスト

## 1. 基本事項
- [X] プログラム開始時に `*** KJBM030 START ***` が表示されること
- [X] プログラム終了時に各ファイルの処理件数（ITF, IMF, OTF）が表示されること
- [X] プログラム終了時に `*** KJBM030 END ***` が表示されること

## 2. チェック対象外レコードの処理
- [X] ITF.エラー区分(5)がスペース以外の場合、マッチングを行わずそのまま出力されること

## 3. マッチング処理（正常系・異常系）
仕様書「3.2 マッチング処理」に基づく確認

### マスタ一致（ITF ＝ IMF）
- [X] 商品番号が一致した場合、IMFの商品名が正しくセットされること
- [X] 商品番号が一致した場合、IMFの単価が正しくセットされること
- [X] 商品番号が一致し、ITF.エラー区分(6)がスペースの場合、「数量 × 単価」が金額にセットされること
- [X] 商品番号が一致し、ITF.エラー区分(6)がスペース以外の場合、金額に 0 がセットされること

### マスタ不一致（ITF ＜ IMF）
- [X] マスタに存在しない商品番号の場合、ITF.エラー区分(5)に '2' がセットされること

### マスタスキップ（ITF ＞ IMF）
- [X] ITFの商品番号に追いつくまで、IMFが正しく読み飛ばされること

## 4. 境界値・特殊ケース
- [X] 入力ファイル（ITF）が空の場合、全件数 0 で正常終了すること
- [X] 商品マスタ（IMF）が空の場合、全レコードが不一致エラー（エラー区分(5) ='2'）になること
- [X] 同一の商品番号が複数連続（N1）しても、すべて正しくマスタ情報が反映されること
- [X] ITFの読み込みが先に終わった場合、残りのIMFを読み込まずに正常終了すること
- [X] IMFの読み込みが先に終わった場合、残りのITFがすべて不一致エラー（エラー区分(5)='2'）になること
