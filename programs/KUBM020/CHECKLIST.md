# KUBM020 単体テストチェックリスト

## 1. 基本動作確認
- [X] 1.1 開始メッセージが表示されること (`*** KUBM020 START ***`)
- [X] 1.2 終了メッセージが表示されること (`*** KUBM020 END ***`)
- [X] 1.3 処理件数（ITF-CNT, OTF-CNT）が正しく表示されること

## 2. 集計ロジック（コントロールブレイク）
- [X] 2.1 同一キー（商品番号＋受注年月）のレコードが1つに集計されているか
- [X] 2.2 キーが変わったタイミングで、正しく前のグループが出力されているか
- [X] 2.3 【最重要】 ファイルの終端（EOF）で、最後のグループが漏れずに出力されているか
- [X] 2.4 キーが変わった際、次のグループのために合計金額が 0 にリセットされているか

## 3. 金額の計算
- [X] 3.1 データ区分 '1' の場合に、金額が正しく加算されているか
- [X] 3.2 データ区分 '9' の場合に、金額が正しく減算されているか
- [X] 3.3 マイナスの集計結果（返品の方が多い場合など）が正しく出力されるか（必要に応じて）
## 4. 項目転送とクリア
- [X] 4.1 金額以外の項目が、同一キー内の先頭レコードから転送されているか
- [X] 4.2 出力レコード（OTF-REC）が編集前に正しくスペースクリアされているか
- [X] 4.3 予備項目（FILLER）がスペースになっているか

## 5. 異常系・境界値
- [X] 5.1 入力ファイルが 0 件の場合、エラーにならず出力 0 件で終了するか
- [X]5.2 入力ファイルが 1 件のみの場合、正しく出力されるか
- [X] 5.3 全レコードが同一キーの場合、出力が 1 件になるか
