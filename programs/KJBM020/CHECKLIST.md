# KJBM020 単体テストチェックリスト

## 確認内容の概要
受注チェックファイルの各項目に対する属性チェック、およびエラー区分のセット処理が、プログラム設計書（PRG_KJBM020）の「チェック詳細」通りに動作することを確認する。

## 1. 共通項目・メッセージ表示
- [X] プログラム開始時に `*** KJBM020 START ***` が表示されること
- [X] プログラム終了時に以下の形式で件数が表示されること
  - `ITF-CNT: （読み込み件数）`
  - `OTF-CNT: （出力件数）`
- [X] プログラム終了時に `*** KJBM020 END ***` が表示されること

## 2. 形式チェック：正常系テスト
仕様書の「正常条件」を満たしたとき、エラー区分がセットされず、データが正しく転記されることを確認する。

- [X] (1) データ区分が '1' または '9' の場合、エラー区分(1)がスペースであること
- [X] (2) 受注番号が数字かつゼロ以外（例：0001）の場合、エラー区分(2)がスペースであること
- [X] (3) 受注日付がサブプログラム **KCBS010** で正常と判定された場合、以下のようになること
  - エラー区分(3)がスペースであること
  - 出力レコードの受注日付に、西暦8桁（YYYYMMDD）が転記されていること
- [X] (4) 商品番号が数字かつゼロ以外の場合、エラー区分(5)がスペースであること
- [X] (5) 数量が数字かつ 1 ～ 999 の範囲内の場合、エラー区分(6)がスペースであること
- [X] (注) 未使用のエラー区分(4)が、常にスペースのままであること

## 3. 形式チェック：異常系テスト
仕様書の「エラー時の処理」に従い、該当する項目のエラー区分に正しく '1' がセットされることを確認する。

- [X] (1) データ区分が '1', '9' 以外（例：'0', 'A', スペース）の場合、エラー区分(1)に '1' がセットされること
- [X] (2) 受注番号が数字でない、またはゼロ（0000）の場合、エラー区分(2)に '1' がセットされること
- [X] (3) 受注日付がサブプログラム **KCBS010** でエラー（'E'）と判定された場合、エラー区分(3)に '1' がセットされること
- [X] (4) 商品番号が数字でない、またはゼロの場合、エラー区分(5)に '1' がセットされること
- [X] (5) 数量が数字でない、または 1 ～ 999 の範囲外（例：000、1000）の場合、エラー区分(6)に '1' がセットされること

## 4. ファイル制御・件数確認
- [X] 入力ファイルが 0 件（空ファイル）の場合、出力ファイルも 0 件で正常終了すること
- [X] 入力ファイルの全レコードが処理され、ITF-CNT と OTF-CNT が一致すること
