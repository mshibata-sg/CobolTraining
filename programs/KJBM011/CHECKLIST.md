# KJBM011 単体テストチェックリスト

## 確認内容の概要
受注テーブル（KCCMJUCHU）からデータを取得し、受注チェックファイル（OTF）へ正しく出力されること、および件数・カーソル処理・エラー処理が仕様通り動作することを確認する。

## 1. 共通項目・メッセージ表示
- [x]  プログラム開始時に `*** KJBM011 START ***` が表示されること
- [x] プログラム終了時に以下の形式で件数が表示されること
 - `OTF-CNT: （出力件数）`
- [x] プログラム終了時に `*** KJBM011 END ***`が表示されること

## 2. DB接続・初期処理
- [x] データベース接続（CONNECT）が正常終了すること（SQLCODE = 0）
- [] 接続エラー時にエラーメッセージ（SQLCODE / SQLERRMC）が表示されること
- [x] 出力ファイル（OTF-FILE）が正常にOPENされること
- [x] カーソル（CUR-JUCHU）が正常に宣言されること
- [x] カーソルOPENが正常終了すること

## 3. SELECT・取得処理（正常系）
- [x] テーブル KCCMJUCHU のデータが正しく取得できること
- [x] FETCHにより1件ずつデータが取得されること
- [x] 各項目が正しくホスト変数に格納されること
  CMJUCHU_DATA_KBN
  CMJUCHU_JUCHU_NO
  CMJUCHU_JUCHU_DATE
  CMJUCHU_SHOHIN_NO
  CMJUCHU_SURYO

## 4. 出力項目チェック（正常系）
- [x] OTFレコードが初期化（SPACE / ZERO）されていること
- [x] DBデータがOTFレコードへ正しく転記されること
  データ区分 → JF020-DATA-KBN
  受注番号 → JF020-JUCHU-NO-X
  受注日付 → JF020-JUCHU-DATE6
  商品番号 → JF020-SHOHIN-NO
  数量 → JF020-SURYO-X
- [x] 固定値項目が正しく設定されること
  エラー区分 → SPACE
  商品名 → SPACE
  単価 → ZERO
  金額 → ZERO

## 5. 繰り返し処理（重要）
- [x] SQLCODE = 100（データなし）になるまでループすること
- [x] 全件処理されること
- [x] 処理件数（WK-COUNT）が出力件数と一致すること

## 6. 異常系（エラー処理）
- [X] カーソルOPEN失敗時に ERROR-RTN が実行されること
- [X] エラー時に以下が表示されること
  SQL ERROR : xxx
  MESSAGE   : xxx
- [X] エラー時に RETURN-CODE=9 で異常終了すること


## 7. ファイル出力・件数確認
- [x] OTFファイルにレコードが正しく書き込まれること
- [x] 出力件数（WK-COUNT）が実際のレコード数と一致すること
- [X] データ件数0件の場合、出力ファイルも0件で終了すること

## 8. 終了処理
- [x] カーソルが正常にCLOSEされること
- [x] DBが正常にDISCONNECTされること
- [x] ファイルが正常にCLOSEされること

## 9.補足（今回の重要チェックポイント）
- [x] 接続文字列に不要項目（CONNSETTINGS）が含まれていないこと
- [x] OTFファイルの書き込み権限があること
- [x] プログラムがコンパイル済みであること（.COB直接実行していない）
