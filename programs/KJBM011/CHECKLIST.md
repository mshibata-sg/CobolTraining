# KJBM011 単体テストチェックリスト

## 確認内容の概要
受注テーブル（KCCMJUCHU）のデータが正しくOTFファイルへ出力されていること、および件数の整合性と出力内容の正確性を確認する。

## 1. 共通項目・メッセージ表示
- [x]  プログラム開始時に `*** KJBM011 START ***` が表示されること
- [x] プログラム終了時に以下の形式で件数が表示されること
 - `OTF-CNT: （出力件数）`
- [x] プログラム終了時に `*** KJBM011 END ***`が表示されること
- [X] 接続エラー時にエラーメッセージ（SQLCODE / SQLERRMC）が表示されること

## 2. DB接続・初期処理
- [x] データベース接続（CONNECT）が正常終了すること（SQLCODE = 0）
- [x] 出力ファイル（OTF-FILE）が正常にOPENされること

## 4. 出力項目チェック（正常系）
- [x] OTFレコードが初期化（SPACE / ZERO）されていること
- [x] DBデータがOTFレコードへ正しく転記されること
  データ区分 → JF020-DATA-KBN
  受注番号 → JF020-JUCHU-NO-X
  受注日付 → JF020-JUCHU-DATE6
  商品番号 → JF020-SHOHIN-NO
  数量 → JF020-SURYO-X
- [x] 固定値項目が正しく設定されること
  エラー区分 → SPACE
  商品名 → SPACE
  単価 → ZERO
  金額 → ZERO

## 5. 異常系（境界値・エラー処理）
- [X] カーソルOPEN失敗時に ERROR-RTN が実行されること
- [X] エラー時に RETURN-CODE=9 で異常終了すること
- [ ] 数値項目に文字列を設定した場合にエラーとなること（型チェック）
- [ ] 数値項目に桁数超過の値を設定した場合にエラーとなること
- [ ] 文字項目に桁数超過の文字列を設定した場合にエラーとなること
- [ ] NOT NULL項目にNULLを設定した場合にエラーとなること

## 6. 境界値
- [X] データ件数が0件・1件・複数件で正しく出力されること
- [] 数量項目が0、文字項目が空白でも正しく出力されること
- [x] 数量項目が最大値、文字項目が最大桁でも正しく出力されること

## 7. ファイル出力・件数確認
- [x] OTFファイルにレコードが正しく書き込まれること
- [x] 出力件数（WK-COUNT）が実際のレコード数と一致すること
