> 凡例:
> * **X**: 英数字
> * **N**: 日本語
> * **S**: 符号
> * **9**: ゾーン形式10進数
> * **9P**: パック形式10進数
> * **△**: 半角スペース
> * **桁数**: 数値項目(`9`)のとき整数部の桁数
> * **小数**: 小数部の桁数（例: 桁数5、小数2 → `PIC 9(5)V9(2)`）。実際には整数部と小数部を合計した桁数分の領域が確保されます。
